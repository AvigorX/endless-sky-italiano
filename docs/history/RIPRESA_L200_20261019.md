## 1. Mandato e regole non negoziabili

Si traduce in **italiano** *Endless Sky* (testi sotto `data/`), **a lotti**, dentro `staging/editorial/L<n>_<data>_<ora>/`.
Ogni lotto si chiude con **due script indipendenti a exit code** e con i documenti.

1. **Lo staging non è approvazione**: nessuna scrittura su `state.db`, nessun caricamento nel gioco, nessun commit nel
   repo originale.
2. **Un'unità `APPROVED` non si riscrive**: si riproduce **alla lettera** dal campo `italian` del database.
3. **I numeri si misurano**, mai si deducono: ogni misura in un documento viene da un comando eseguito.
4. **Le asserzioni vuote si scrivono** (`== []`, `== 0`): «niente da controllare» e «controllo mancato» si distinguono.
5. **Un controllo che non può fallire non è un controllo** (`ck(..., True)`): si toglie.
6. **Si corregge la resa, non il controllo** — e viceversa: se l'asserzione è sbagliata si corregge **l'asserzione**,
   dichiarandolo.
7. **`UI_LABEL` e `VALUE` non si traducono**; `TEXT` e `DIALOG` **in prosa** sì.
8. **I nomi propri restano inglesi**: navi, armi, moduli, specie, mondi, e le fazioni non umane (`Hai`, `Unfettered`).
9. **Registro unico «tu»** per il giocatore; la cortesia «Lei» si corregge.
10. **Coerenza cross-lot**: stessa stringa inglese → stessa resa italiana, verificata contro lo staging esistente; se le
    rese sono concorrenti, se ne sceglie una **già esistente** e la si dichiara.
11. **Un lotto terminale usa l'invariante di FILE**, non il confronto con un confine inesistente.
12. **Un documento superato si marca `OBSOLETO`**; un handoff nuovo diventa il contratto attivo.

## 7. Definizione di «fatto» e batteria finale

```bash
python staging/editorial/L<n>_<data>/check.py     # "FAIL totale: 0", exit 0
python staging/editorial/L<n>_<data>/verify.py    # "FAIL: 0", exit 0
python staging/editorial/tools/state.py           # "ESITO: OK", 8/8
python staging/editorial/tools/check_handoff.py HANDOFF_L<n+1>_<data>.md   # "FAIL: 0 / 22" (23 se cita due lotti)

```

Un lotto è **chiuso** solo se `check.py` e `verify.py` escono **0** e la batteria non stampa nessun `ROSSO`.
