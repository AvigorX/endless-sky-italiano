## 1. Mandato e regole non negoziabili

Si traduce in **italiano** *Endless Sky* (testi sotto `data/`), **a lotti**, in `staging/editorial/L<n>_<data>_<ora>/`.
Ogni lotto si chiude con **due script indipendenti a exit code** e con i documenti.

1. **Lo staging non è approvazione**: nessuna scrittura su `state.db`, nessun caricamento nel gioco, nessun commit.
2. **Un'unità `APPROVED` non si riscrive**: si riproduce **alla lettera** dal campo `italian`.
3. **I numeri si misurano**, mai si deducono.
4. **Le asserzioni vuote si scrivono** (`== []`, `== 0`).
5. **Un controllo che non può fallire non è un controllo**.
6. **Si corregge la resa, non il controllo** — e viceversa.
7. **`UI_LABEL` e `VALUE` non si traducono**; `TEXT`, `DIALOG`, `NEWS`, `MISSION_TEXT` e `LOGBOOK` **in prosa** sì.
8. **I nomi propri restano inglesi**; **i nomi comuni di istituzione e di evento si traducono**.
9. **Registro unico «tu»**; la cortesia «Lei» si corregge.
10. **Coerenza cross-lot**: stessa stringa inglese → stessa resa; **vince la dominante misurata**.
11. **Un lotto terminale usa l'invariante di FILE**; gli altri l'invariante di **segmento**.
12. **I frammenti devono comporre**.
13. **Il genere non si inventa**.

## 6. Metodo per lotto (7 passi) e trappole

1. **Preflight**: `state.py` → `ESITO: OK`, 8/8.
2. **Export** (`directory` **prima** del percorso), poi lettura del `source.json`.
3. **Conteggio misurato**: `Counter(kind)`, **contesti**, tab/virgolette/apici **per unità**, token.
4. **Traduzione** in `parts/partNN.json` — cercando prima le **frasi fisse** e le **stringhe già tradotte**.
5. **`check.py`**: tipi, sequenza dei contesti, segni **per unità**, token, gate, `PENDING`, coerenza cross-lot.
6. **`verify.py`**: riga grezza, DB, conteggi prima/dopo, **confine misurato**; se terminale, invariante di FILE.
7. **Documenti**: `STATO.md`, `REPORT.md`, `review.md`, `HANDOFF_L<n+1>`, i due checkpoint, questa ripresa, batteria,
   `git status`.

| n. | trappola | come si evita |
|---|---|---|
| 46 | `write_file` può rispondere «ok» senza creare il file | scratch → `cp` → `ls -la` |
| 47 | **la cella `Contesti` vuole il primo E l'ultimo** | con **un solo contesto**: `da \`A\` a \`A\`` |
| 48 | **`Confine dopo` vuole la forma `riga N apre \`contesto\``** | con «resta in» il checker dà `1 FAIL` (L259) |
| 88 | **la copertura si asserisce per segmento** | il lotto afferma le **proprie** righe, non il futuro |
| 93 | **il numero di controlli si conta dal sorgente** | `grep -c '^ck(' check.py` |
| 96 | **la cella `Unità` deve essere un numero nudo** | `int()` nel checker |
| 99 | **un apostrofo italiano dentro un letterale Python rompe il file** | virgolette doppie o triple |
| 116 | **il contratto vuole la riga del residuo di `human missions.txt`** | `**N unità / M parole** dopo la riga 6428` |
| 118 | **nel lotto terminale `Confine dopo` deve cominciare con «fine file»** | altrimenti `1 FAIL` |
| 120 | **un `len(units)` è il lotto, non il file** | contare tutti i `translation.json` |
| 122 | **il numero dei token non è controllato dal checker** | sommarli nella shell |
| 127 | **il contratto deve contenere anche la riga di `data/map planets.txt`** | altrimenti `1 FAIL` |
| 140 | **un file di dialogo ha decine di tab e virgolette** | misurarli **per unità**, non sul totale |
| 141 | **un `verify.py` che non compila non è un test fallito** | guardare il lint del salvataggio |
| 142 | **le rese lunghe gonfiano il rapporto senza guadagno** | accorciare prima di allargare il gate |
| 143 | **una citazione può essere aperta e NON chiusa** | riprodurla com'è (L257 u12, L258 u5) |
| 144 | **un'asserzione tautologica non è un controllo** | `righe == righe | …` passerebbe sempre |
| 145 | **un lotto che attraversa un cambio di missione** | verificare la **sequenza** dei contesti |
| 146 | **`Confine dopo` con «resta in» non viene parsato** | la regex vuole `riga (\d+) apre \`([^\`]+)\`` |
